# Сайт Кирилла Юрьевича Орлова

Персональный сайт эндоваскулярного нейрохирурга. Проект статический: он быстро загружается, не требует базы данных и автоматически публикуется через GitHub Pages.

## Структура

```text
src/
├── html/       исходная HTML-страница
├── css/        стили и адаптивность
├── js/         небольшие сценарии интерфейса
├── images/     только изображения сайта
└── public/     robots.txt, sitemap.xml и manifest
scripts/        сборка проекта
tests/          автоматические проверки
dist/           готовая публикационная версия
.github/        автоматическая публикация GitHub Pages
```

`dist/index.html` находится в корне сборки, потому что это стандартная точка входа веб-сервера. Внутри `dist` остаются отдельные папки `css`, `js` и `images`.

## Команды

Требуется Node.js 22 или новее. Сторонние пакеты устанавливать не нужно.

```bash
npm run build
npm test
```

После изменения ветки `main` GitHub Actions заново собирает `dist`, проверяет сайт и публикует его в GitHub Pages.

## Что не хранится в репозитории

В репозиторий не входят презентации, медицинские документы, рабочие архивы, кеши, зависимости, локальные настройки и секреты. Правила исключения находятся в `.gitignore`.

## Права на материалы

Исходный код, тексты и изображения не распространяются по открытой лицензии. Их использование требует разрешения правообладателя.
